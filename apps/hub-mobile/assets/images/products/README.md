Product pictures

One picture per product, named after the product id: `prod-01.jpg`, `prod-02.jpg`, ...
Square, about 900 x 900 px, JPEG (quality 85 keeps each file near 200-400 KB). A product without a file here keeps
the drawing made in code (lib/shared/product_image.dart), so a missing file is never an error.

The five pictures of the demo products were designed with an image generator for this demo; they show invented
packaging (brand "Trà Việt") and are meant to be replaced by the cooperatives' real product photos.
