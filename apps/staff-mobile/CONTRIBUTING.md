# Contributing

Thanks for helping improve Tea Work.

## Reporting bugs and ideas

Open an issue at <https://github.com/Vudinhdat02/appReceiveWork/issues> with the app version (Profile tab), the Android version and device, the steps to reproduce and a screenshot if possible. Never attach real employee data.

## Making changes

1. Fork the repository and create a branch from `main`.
2. `./gradlew assembleDebug testDebugUnitTest` must pass. If you change a screen, the screenshots in `docs/screenshots` are regenerated by the test; review them before committing.
3. Keep composables stateless; state and actions live in the feature's view model, data access behind `StaffRepository`.
4. Keep the API models in sync with the [staff API contract](../staff-desktop/docs/mobile-api.md).
5. Code identifiers are English; user-facing text is Vietnamese.
6. Add the SPDX header to every new file:
   ```kotlin
   // SPDX-License-Identifier: MIT
   // SPDX-FileCopyrightText: 2026 <your name>
   ```
7. Record user-visible changes in `CHANGELOG.md` and new libraries in `DEPENDENCIES.md`, then open a pull request.

By contributing you agree that your work is released under the [MIT License](LICENSE).
