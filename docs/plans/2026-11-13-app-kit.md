# App Kit and Deeper Business Apps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The four business mini-apps look and work like finished applications (overview, in-app navigation, search, filters, paging, print, CSV, inline form errors) on one shared kit, and an installed app can be upgraded in place.

**Architecture:** One canonical kit — CSS in the web app's `/dxos-app.css`, Jinja macros and a small Python module under `platform/appkit/` copied into each app by `make appkit-sync` — so every app renders the same components. Pages stay server-rendered without scripts. The core gains two small allowances (downloads from the app frame, `content-disposition: attachment` through the proxy) and the CLI gains `./dxos upgrade`.

**Tech Stack:** FastAPI + Jinja2 mini-apps (Python 3.12, psycopg), CSS, Next.js 14 proxy, Python CLI (`platform/cli`), bash (`./dxos`), Playwright.

**Spec:** `docs/specs/2026-11-13-app-kit-design.md`

## Global Constraints

- English-only identifiers; English Conventional Commits; author `maiychrus25 <ninhkhuongpl7@gmail.com>` (`git -c user.name=maiychrus25 -c user.email=ninhkhuongpl7@gmail.com commit`); no Co-Authored-By trailer; no mention of any AI tool; no push.
- SPDX header (`MIT`, `2026 OpenTea Developers`) on every new text file.
- Never read or print `docker/.env.local` or the repo-root `.env.local`. Never delete `docker_*` volumes. Never run `docker compose up` by hand: use `make …` or `./dxos …` (`make web-up`, `make gateway-up`). Full-stack rounds use `COMPOSE_PROJECT_NAME=dxos-clean`.
- No new dependency anywhere. No JavaScript in mini-app pages; the CSP of `/apps/` does not change; no inline `style` attributes (CSP `style-src 'self'`).
- User-facing text is Vietnamese with full diacritics; money is integer VND shown as `9.000 ₫`; dates `13/11/2026`.
- Every query filters on `htx_code` from the token; search and filter values reach SQL as parameters only.
- **Existing HTTP contracts stay:** paths, methods, form field names, status codes and `Location` targets of today's routes do not change; new behaviour lives at new routes or as added content. Existing tests keep passing unchanged unless a brief names the change.
- Shared conventions for new pages: query parameters `q` (search, `ILIKE`, case-insensitive, accent-sensitive), `from` and `to` (`YYYY-MM-DD`), `status`, `page` (1-based); lists newest first, 25 rows per page; CSV at `<list path>/export.csv`; print pages at `<item path>/print`, opened with `target="_top"`.
- CSV: UTF-8 with BOM, CRLF, `content-disposition: attachment`, ASCII file name `<app>-<htx>-<name>-<YYYY-MM-DD>.csv`, text cells starting with `=`, `+`, `-` or `@` prefixed with `'`; only rows and columns the caller's role may see on screen; the current filters apply.
- Kit copies (`<package>/appkit.py`, `<package>/templates/kit.html`) are never edited in an app; a gap in the kit is reported, not patched locally.
- No new database migration unless a task names it; any migration is additive and idempotent.
- App versions go from `0.1.0` to `0.2.0` in the four apps this plan changes; the web package version is `1.11.0` from Task 0.
- UI follows `DESIGN.md` tokens: light and dark, no page-level horizontal overflow at 390 px, `:focus-visible` states, empty states.

## Review Focus

1. A filter or search value containing `%`, `_`, `'` or `;` must be treated as text — each app: test `search treats wildcards as text`.
2. `page=0`, `page=abc`, `page=999999` must show a valid page, never an error — Task 0 test `page_of clamps`, each app: one list test.
3. A CSV must not leak another HTX's or another household's rows — each app: test `export only holds the caller's rows`.
4. A CSV cell such as `=HYPERLINK(...)` typed by a guest must not run as a formula — Task 0 test `csv_response escapes formula cells`.
5. An upgrade must not change who has the app enabled — Task U test `upgrade keeps enablements`.

`appkit.py` (stdlib + `starlette.responses.Response`; first line after the SPDX header: `# Copied by make appkit-sync from platform/appkit/appkit.py. Edit the original.`):

```python
PAGE_SIZE = 25
@dataclass(frozen=True)
class Page: number: int; size: int; total: int      # properties: pages (>= 1), offset, has_prev, has_next
def page_of(raw: str | None, total: int, size: int = PAGE_SIZE) -> Page          # missing/invalid -> 1; beyond the end -> last page
def parse_date(raw: str | None) -> date | None                                    # exactly YYYY-MM-DD, else None
def parse_int(raw: str | None, low: int, high: int) -> int | None
def like_pattern(q: str) -> str                                                    # escapes \ % _ and wraps in %...% for ILIKE ... ESCAPE '\'
def money(vnd: int) -> str                                                         # 9000 -> "9.000 ₫"
def number(value, digits: int = 1) -> str                                          # Decimal("12.50") -> "12,5"; 8 -> "8"
def vn_date(value: date | datetime) -> str                                         # "13/11/2026"
def vn_datetime(value: datetime) -> str                                            # "13/11/2026 08:11", Asia/Ho_Chi_Minh
@dataclass(frozen=True)
class ChartRow: label: str; value: str; percent: int                              # percent 0..100 of the largest value
def chart_rows(pairs: Sequence[tuple[str, Decimal | int]], fmt=number) -> list[ChartRow]
def csv_filename(app_id: str, htx_code: str, name: str, day: date) -> str         # ASCII only
def csv_response(filename: str, header: Sequence[str], rows: Iterable[Sequence]) -> Response
def shell_url(role: str, app_id: str, path: str = "/") -> str                     # "/manager/apps/tea-shop/orders"
```

- Web: `StoreApp.installedVersion: string | null` (from `platform.installed_apps.version`); when it differs from the catalogue version the card and the detail header show a pill `Có bản mới` and the detail's "Thông tin" shows `Bản đang chạy: <installed>` with the line `Quản trị máy chủ chạy ./dxos upgrade miniapps/<id> để cập nhật.`
