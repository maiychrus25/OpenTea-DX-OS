# Hồ sơ du lịch vùng chè

Hồ sơ đầy đủ cho từng sản phẩm, dịch vụ, vị trí, điểm đến. Bản tóm tắt nhanh ở `../Cam_nang/`.

| Hồ sơ | Dùng cho |
| --- | --- |
| [01 Hái chè](01-hai-che.md) | hộ có nương đón khách |
| [02 Sao, vò chè](02-sao-che.md) | hộ có xưởng |
| [03 Thưởng trà](03-thuong-tra.md) | người pha trà |
| [04 Ăn uống](04-an-uong.md) | bếp |
| [05 Homestay](05-luu-tru.md) | chủ nhà |
| [06 Người hướng dẫn](06-huong-dan-vien.md) | hướng dẫn viên tại điểm |
| [07 Đi bộ, suối](07-di-bo-suoi.md) | tuyến ngoài trời |
| [08 Đoàn học sinh](08-hoc-sinh.md) | đón trường học |
| [09 Điểm đến](09-diem-den.md) | thông tin từng điểm, chỗ còn thiếu |
| [10 Quản lý điểm](10-quan-ly-diem.md) | hợp tác xã, ban quản lý |

---
**Cách đọc:** mục ghi `[ASEAN x.y.z]` là tiêu chí trong *Tiêu chuẩn du lịch cộng đồng ASEAN* (tự nguyện, dùng để chứng nhận, không phải luật). `[NĐ168]` là Nghị định 168/2017, `[Luật DL]` là Luật Du lịch 2017. `(gợi ý)` là đề xuất của dự án, cần hợp tác xã thử và chỉnh.
