# Dữ liệu dạng bảng

CSV (UTF-8, mở được bằng Excel). Mỗi dòng có cột nguồn. **Số theo thời điểm công bố**, không phải hiện trạng.

| File | Nội dung |
| --- | --- |
| `dich_hai_che.csv` | Tỷ lệ búp, lá bị hại, diện tích, xã theo thông báo của Chi cục (26/11/2025, 20/5 và 27/5/2026) |
| `du_bao_dich_hai_2026.csv` | Tháng cao điểm theo dự báo vụ Xuân và vụ Mùa 2026 |
| `vung_che.csv` | Diện tích, chứng nhận, hợp tác xã theo vùng |
| `chung_nhan_toan_tinh.csv` | Mã số vùng trồng, VietGAP, hữu cơ, OCOP |
| `ocop_che_5_sao_2025.csv` | Ba sản phẩm chè đạt 5 sao quốc gia năm 2025 |
| `diem_du_lich_cong_dong.csv` | Sáu điểm được công nhận (nguồn 2023) |

**Còn thiếu:** thông báo dịch hại các tuần khác (tìm được ít), danh sách hợp tác xã chè, danh sách mã số vùng trồng từng đơn vị.
Chưa phần mềm nào đọc các file này.
